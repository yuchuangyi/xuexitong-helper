## 📖 这是什么

一个跑在浏览器里的 Tampermonkey 用户脚本。装上之后，打开网课页面会自动注入一个悬浮面板，帮你把"看视频、过任务点、做随堂练习"这些重复劳动交给程序处理，答题部分由 **DeepSeek** 大模型现场推理生成答案。

它不是一个独立软件，**只是网页增强脚本** —— 不修改平台数据、不代刷、不上传你的账号信息。所有答题请求由你自己的 API Key 直接发往 `api.deepseek.com`，脚本作者看不到任何内容。

## ✨ 功能特性

### 🎬 视频任务
- **自动播放** —— 进入章节自动找到播放器并开始播放，无需手动点击
- **自动静音** —— 默认静音，避免自动播放被浏览器策略拦截
- **任意倍速** —— 默认 `1.5×`，设置里可在 `1× ~ 16×` 之间以 `0.5` 为步进调整
- **断点续播** —— 页面刷新 / 切换任务点后自动接续播放进度
- **播完自动下一个** —— 当前视频结束自动跳转到下一个未完成的任务点

### 📌 任务点处理
- 自动识别**视频 / 文档 / 图文**三类任务点，分别走不同的完成策略
- 文档类任务点自动滚动到页面底部，触发"阅读完成"判定
- 图文资源支持**最大停留时长**控制（默认 150 秒，可调 30 ~ 1800 秒），避免死循环原地打转
- 任务点进度以百分比为准，`0%` / `8%` 不会被误判为已完成（v0.3.2 修复）
- 滚动容器识别带多套回退，防止把外层包裹容器当成滚动区导致反复刷页（v0.3.3 修复）

### 🧠 AI 自动答题
- 覆盖题型：**单选题 / 多选题 / 判断题 / 填空题 / 简答题**
- 答案由 **DeepSeek V4.1（`deepseek-flash`）** 现场推理生成，带简短解析
- **相似度阈值**：答案与选项文本相似度超过阈值（默认 `85%`）才会自动选择，低于阈值则跳过该题，不乱填
- **正确率阈值**：整体正确率达到阈值（默认 `85%`）才自动提交，避免低分交卷
- 支持**随堂练习 / 章节测验 / 作业 / 考试**等多种场景
- 答题后自动切题 / 提交，可单独关闭
- 面板「答题」页会实时列出已抓到的题目与作答状态，可随时暂停

### 🖥 悬浮面板
- 五页签结构：**首页（运行日志） / 答题（题目列表） / 设置 / 教程 / 协议**
- 可自由拖动、可最小化，位置记忆到本地
- 全程日志可视化，出问题把日志贴出来就能定位（脚本内部对选择器做了多套回退，任何异常都不会抛到宿主页面）

## 🚀 安装

### Step 1. 装 Tampermonkey

先给浏览器装用户脚本管理器（任选其一）：

| 浏览器 | 扩展商店 |
| :--- | :--- |
| Chrome / Edge | [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) |
| Firefox | [Tampermonkey](https://addons.mozilla.org/firefox/addon/tampermonkey/) |

装好后确认浏览器工具栏里出现了 Tampermonkey 图标。

### Step 2. 装脚本

**方式 A：一键安装 · jsDelivr 源（国内推荐，不用翻墙）**

把下面这行完整复制到浏览器地址栏回车，Tampermonkey 会自动弹出安装页，点「安装」即可：

```
https://cdn.jsdelivr.net/gh/yuchuangyi/xuexitong-helper@main/%E9%98%BF%E5%A2%A8%C2%B7%E7%BD%91%E8%AF%BE%E5%8A%A9%E6%89%8B.user.js
```

**方式 B：一键安装 · GitHub 原链（需要能访问 GitHub）**

```
https://raw.githubusercontent.com/yuchuangyi/xuexitong-helper/main/%E9%98%BF%E5%A2%A8%C2%B7%E7%BD%91%E8%AF%BE%E5%8A%A9%E6%89%8B.user.js
```

**方式 C：手动导入（以上都打不开时用这个，最稳）**

1. 打开 [仓库主页](https://github.com/yuchuangyi/xuexitong-helper)，下载 [`阿墨·网课助手.user.js`](./阿墨·网课助手.user.js) 到本地
2. 打开 Tampermonkey 面板 → 「添加新脚本」
3. 删掉编辑器里的默认模板，把文件内容全部粘贴进去，`Ctrl + S` 保存

安装完成后，打开任意受支持的网课页面，右上区域会出现悬浮面板。

> 📌 **关于更新**：jsDelivr 源缓存约 12 小时，作者更新脚本后你可能不会立刻拿到新版。想立即更新就走方式 B，或者在 Tampermonkey 的脚本详情页手动点「检查更新」。

### Step 3. 配置 DeepSeek API Key（关键）

**不配 Key 的话，视频和任务点功能照常工作，但答题功能不可用。** 脚本本身不内置任何 Key。

1. 打开 [platform.deepseek.com](https://platform.deepseek.com/)，注册 / 登录
2. 左侧菜单 → **API keys** → **创建 API key**，复制生成的 `sk-` 开头的字符串（只显示一次，记得存好）
3. 在 **API 充值** 页面充值（按 token 计费，答一份普通作业通常只花几分钱）
4. 回到网课页面 → 点击悬浮面板 → **设置** 页签 → 找到 `DeepSeek 设置` → 把 Key 粘贴进 `apiKey` 输入框
5. 点保存。配置存在浏览器本地（Tampermonkey 存储），不会同步到任何服务器

> 模型默认为 `deepseek-flash`，接口地址 `https://api.deepseek.com`，一般不需要改。

### Step 4. 开始使用

装好并配好 Key 后，正常进入课程页面即可：

- **超星**：进入课程 → 章节学习页（`studentstudy`）
- **智慧树**：进入课程 → 学习页 / AI 课程知识学习页
- **Unipus**：进入课程学习页

面板出现在页面右上区域（默认 `800, 200` 位置），可以拖到顺手的地方。切到「首页」页签能看到实时日志：脚本是否识别到页面、找到了几个任务点、正在播放什么、答了几道题。

## ⚙️ 设置项说明

面板 → **设置** 页签，按当前平台展示对应配置项。

### 超星学习通

| 分组 | 设置项 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| 章节设置 | 章节作业自动提交 | `开` | 章节内的作业答完自动点提交 |
| 章节设置 | 是否自动下一章节 | `开` | 当前章节任务点全部完成后自动进入下一章 |
| 章节设置 | 只答题，不做其他 | `关` | 打开后只处理答题，不碰视频和任务点 |
| 考试设置 | 是否自动切换 | `开` | 答完一题自动切到下一题 |

### 知到智慧树（AI 课程）

| 分组 | 设置项 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| 学习设置 | 自动播放并静音视频 | `开` | 进入页面自动播放并静音 |
| 学习设置 | 学完自动下一个任务点 | `开` | 当前任务点完成后自动跳转 |
| 学习设置 | 视频倍速 | `1.5` | 范围 `1 ~ 16`，步进 `0.5` |
| 学习设置 | 图文资源最多停留秒数 | `150` | 范围 `30 ~ 1800`，防止在图文页空转 |
| 答题设置 | 是否自动答题 | `开` | 出现随堂练习时自动作答 |
| 答题设置 | 答完自动提交 / 切题 | `开` | 答完自动提交并进入下一题 |

### 知到智慧树（普通答题页）、Unipus

| 设置项 | 默认值 | 说明 |
| :--- | :--- | :--- |
| 是否自动切换（Unipus：是否自动下一题） | `开` | 答完自动进入下一题 |

### 其他参数（全平台通用）

| 设置项 | 默认值 | 说明 |
| :--- | :--- | :--- |
| 切换、答题间隔（秒） | `3` | 每题之间的等待时间，太小容易触发平台风控 |
| 正确率达到多少自动提交 | `85` | 低于该值不自动交卷，留给你自己检查 |
| 答案相似度超过多少选择 | `85` | 低于该值宁可空着也不乱选 |

> 💡 **调参建议**：如果发现题目经常不被作答，先把「答案相似度」降到 `70` 左右试试；如果被平台提示操作过快，把「答题间隔」加到 `5 ~ 8` 秒。

## ❓ 常见问题

<details>
<summary><b>安装链接打不开 / 点了没反应？</b></summary>

- **打不开**：国内访问 `raw.githubusercontent.com` 经常超时，换方式 A 的 jsDelivr 链接
- **打开是一堆代码，没有弹出安装页**：说明 Tampermonkey 没接管这个链接。复制全部代码 → Tampermonkey 面板 →「添加新脚本」→ 粘贴覆盖 → `Ctrl + S`
- **弹出安装页但按钮是灰色的**：点一下「编辑器」左边的「安装」标签页，或者先允许该域名
- 装完记得在 Tampermonkey 的「管理面板」里确认「阿墨·网课助手」前面是**勾选状态**
</details>

<details>
<summary><b>装好了，但页面上没有面板？</b></summary>

按顺序排查：
1. Tampermonkey 图标上的红色数字是否为 `1`，说明当前页有脚本在跑；点图标看「阿墨·网课助手」是否处于启用状态
2. 该页面是否在白名单域名内（见[支持的平台](#-支持的平台)），部分学校自建平台域名不在列表里
3. 是否同时装了其他网课脚本 —— **一个浏览器只留一个**，多个脚本抢同一个播放器必然冲突
4. 强制刷新一次（`Ctrl + F5`），脚本在 `document-start` 注入，缓存可能影响
</details>

<details>
<summary><b>视频不自动播放？</b></summary>

浏览器有"自动播放策略"：页面必须有过一次用户交互（点击、按键）才允许自动播放声音。脚本默认静音，就是为了绕过这条限制。如果仍不播放：
1. 随便点一下页面空白处，再等两秒
2. 检查设置里「自动播放并静音视频」是否被关掉
3. 确认没有别的脚本 / 扩展在干扰播放器
</details>

<details>
<summary><b>答题一直提示"正在解析题目"或"未解析到题目"？</b></summary>

- **没填 API Key**：去设置页填上，这是最常见的原因
- **Key 余额不足**：登录 DeepSeek 平台看余额
- **题目是图片 / 公式**：当前版本只处理文本题干，图片题识别不了
- **题型不支持**：目前覆盖单选、多选、判断、填空、简答五种，其他题型（如连线题、拖拽题）会跳过
</details>

<details>
<summary><b>答案错得多，或者不敢让它自动提交？</b></summary>

把「正确率达到多少自动提交」从 `85` 提到 `100`，脚本就只答题不交卷，你可以在「答题」页签里逐题核对后手动提交。AI 生成答案本身有不确定性，重要考试建议全程盯着。
</details>

<details>
<summary><b>智慧树 AI 课程页（知识学习）适配是怎么回事？</b></summary>

智慧树新版 AI 课程把内容放在 `ai-smart-course-student-pro.zhihuishu.com` 的知识学习页里，页面结构和老版学习页完全不同（React + 懒加载播放器）。脚本对这类页面单独走一套逻辑：多套选择器回退 + 可见性 / 禁用态校验，任何一步失败都只在面板日志里提示，不会把页面搞崩。如果日志报某处失效，把日志贴回 issue 就能定位。
</details>

<details>
<summary><b>脚本会收集我的信息吗？</b></summary>

不会。脚本只有一条对外网络请求：把题目内容发给你自己配置的 `api.deepseek.com` 接口。不采集手机号、学号、学校名，没有埋点，没有作者服务器。
</details>

## 📁 目录结构

```
xuexitong-helper/
├── 阿墨·网课助手.user.js      # 主脚本（单文件，打包后约 270 KB）
├── README.md                  # 本文档
├── LICENSE                    # MIT
├── .gitignore
└── tools/                     # 本地调试脚手架（普通用户不用管）

    ├── probe-video.js         # 探测页面 video 元素与播放状态
    ├── probe-helpers.js       # 通用选择器 / DOM 探测
    ├── cdp.js                 # Chrome DevTools Protocol 连接
    ├── focus-cdp.js           # 聚焦调试目标页
    ├── live-test.js           # 真机联调
    ├── test-automation.js     # 自动化流程验证
    ├── test-config.js         # 配置读写测试
    ├── test-payload.js        # DeepSeek 请求载荷断言
    └── test-zsai.js           # 智慧树 AI 课程页专项测试
```
